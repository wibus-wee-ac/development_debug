Settings 是 Cradle 的配置入口。它以 overlay 形式打开，并按功能区组织用户和管理员设置。

## 先认识这个功能

Settings sidebar 包含 appearance、providers、agents、Jarvis、Chronicle、skills 和 desktop。常见入口是 sidebar 的 Settings 或快捷键入口。

## 主要分区

| Section | Purpose |
| --- | --- |
| Appearance | UI appearance |
| Providers | Provider profiles、health 和 models |
| Agents | Agent identities 和 runtime 相关设置 |
| Jarvis | System agent 相关偏好 |
| Chronicle | 本地 capture 与 memory |
| Skills | Skills inventory 和 import |
| Desktop | Desktop update status |

## 使用建议

先配置 providers，再配置 agents、skills 和 Chronicle。这样 New Chat、Issue agent 和 automation 都能复用同一套运行时基础。

## 使用前先知道

Settings 标签可能与当前 UI 文案略有差异。以当前 app 显示为准。
