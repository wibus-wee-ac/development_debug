Desktop server 是桌面端启动的本地服务。Web workspace 的多数数据和运行时能力都依赖它。

## Overview

桌面端启动时会启动 server 子进程，并在退出前停止 server。Server health 可通过 Devtools 或相关状态入口查看。

## Quick checks

- 桌面端是否仍在运行。
- Web UI 是否能访问本地 API。
- Devtools 的 Server Health 是否正常。
- Provider、Git、Chronicle 等模块是否只有单独失败。

## 常见问题

| Symptom | Likely cause | Recovery |
| --- | --- | --- |
| UI blank | Server not ready or crashed | 重启 desktop app |
| Routes fail | Local API unavailable | 查看 Server Health |
| Plugins unavailable | Desktop plugin runtime failed | 查看 Plugins panel |

## Limits

本文不指定 server 端口、日志路径或 release 安装位置，因为这些需要以当前构建配置为准。
