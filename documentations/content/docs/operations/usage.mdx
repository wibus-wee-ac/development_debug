Usage 用于帮助你理解模型调用的大致消耗。它不是账单系统。

## Overview

Cradle 可以展示 usage logs、token totals、pricing estimates 和 session token progress indicator。可见性取决于 provider 是否返回 usage metadata，以及 Cradle 是否知道对应 model 的价格信息。

## 查看使用量

在 Usage dashboard 或 Chat token indicator 中查看：

- Prompt tokens。
- Completion tokens。
- Total tokens。
- Estimated cost。
- Session progress。

## Limits

- 未知 model 不应估算精确 cost。
- Provider 未返回 usage metadata 时，统计可能为空或不完整。
- Pricing estimate 不等于 invoice。

## Troubleshooting

如果 usage 为空，先确认 provider 是否返回 token usage，再确认 model 是否在 Cradle 的 pricing 数据中。
