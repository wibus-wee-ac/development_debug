Composer 是 Chat session 的输入区域。它负责发送消息、停止当前响应、提及文件、触发 slash commands，并显示 token usage。

## Overview

Composer 的核心工作是把用户输入和 workspace context 组合成下一次 agent run。它不替代完整的 workspace 文件浏览；复杂上下文建议使用 file mentions 或 pack codebase。

## 发送消息

1. 输入任务。
2. 添加需要的文件或路径上下文。
3. 确认 runtime、provider 和 model。
4. 发送。

运行中可以使用 stop/cancel 控制当前响应。

## File mentions

使用文件提及让 agent 读取具体文件。它适合精确上下文，例如一个组件、配置文件或错误日志。

## Slash commands

Slash commands 来自 Chat UI 和 runtime capabilities。不同 runtime 的原生命令不同，文档不列固定全集。

## Limits

- 文件路径必须位于 workspace 可访问范围内。
- Token usage 是估算或 runtime 提供的可见信息，不等同于账单系统。
- 附件能力以当前 UI 与 server 实现为准，未确认的上传行为不在本文承诺。
