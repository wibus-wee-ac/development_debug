Issue detail 是 Kanban 中处理单个任务的地方。它承载任务描述、属性、子任务、评论、活动记录和 agent session 面板。

## Overview

打开 Issue 后，你可以查看 title、description、properties、sub-issues、comments 和 activity。需要 agent 执行时，再从 detail 中委派任务。

## 编辑任务

- 更新标题和描述。
- 调整状态、优先级或其他属性。
- 添加子任务。
- 查看活动记录。
- 追加评论或 prompt。

## 写好 agent 任务

委派前，先让 Issue 描述包含：

- 目标。
- 修改范围。
- 验收条件。
- 不能触碰的文件或行为。
- 推荐验证命令。

## Limits

Issue detail 不是完整项目管理系统的承诺。当前文档只覆盖仓库中可验证的 Issue properties、sub-issues、comments、activity 和 agent session 面板。
