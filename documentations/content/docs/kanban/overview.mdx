Kanban 是 Cradle 中管理 workspace Issue 的视图。它支持 board/list 切换、过滤、排序、搜索、批量选择和 Issue detail。

## Overview

Kanban 面向项目任务，而不是独立的 Chat 历史。你可以从 workspace 进入 board，创建 Issue，查看属性，再把明确的任务委派给 agent。

## 常用操作

- 创建 Issue。
- 在 board 和 list 之间切换。
- 按属性过滤或排序。
- 搜索 Issue。
- 多选 Issue。
- 打开 peek panel 或 detail view。

## 推荐工作流

先把任务拆成 Issue，再把可执行的 Issue 委派给 provider-backed agent。这样 Chat session 与 Issue activity 会保持更清晰的上下文。

## Limits

Board selection 和 URL 行为以当前 tab 实现为准。不要依赖未文档化的深链接格式。
