Cradle 是一个本地优先的 agent workspace。它把你的本地项目、Chat、Issue、自动化、记忆和集成放在同一个工作界面里，让 agent 围绕真实 workspace 工作，而不是停留在孤立对话里。

## 先认识 Cradle

这套文档按你要完成的事情组织：先打开桌面端，再添加 workspace，接着配置模型、开始 Chat、管理 Issue、排查本地运行状态。你可以从下面的地图进入，也可以直接跳到最接近当前任务的页面。

## 管理与排障

Cradle 的复杂能力通常跨越 Web UI、本地 server、桌面 runtime 和插件层。遇到问题时，优先从 [故障处理入口](./troubleshooting/index.mdx) 开始，再进入具体页面。

<Callout type="info">
如果某个能力没有出现在产品界面、Settings 或对应的排障页里，就不要把它当作已经可用的功能。比如远程 workspace、云同步和外部托管不属于当前使用路径。
</Callout>
