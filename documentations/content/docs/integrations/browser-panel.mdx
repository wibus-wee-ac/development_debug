Browser panel 是 Cradle 桌面环境中的浏览器视图。它适合用户查看网页，也可作为 browser-use plugin 的桥接界面。

## Overview

Browser panel 支持 URL navigation、back、forward、reload 和有限的 script injection preset。当前证据显示最多支持多个 tabs，但具体上限以当前 store 实现为准。

## 使用方式

1. 打开 Browser panel。
2. 输入 URL。
3. 使用 back、forward 或 reload。
4. 在需要 agent automation 时确认 browser-use plugin 状态。

## Security

Webview 会加载外部网页。不要在不可信页面中输入敏感信息，也不要批准你不理解的脚本注入或 automation 请求。

## Limits

Browser panel 是 Electron-only 能力。纯 Web 环境可能不可用。
