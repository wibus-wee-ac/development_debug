Slack bridge 是独立 app。排障时不要从 Cradle Web Settings 查找 Slack 页面，而是检查 bridge server、Slack app 和 MCP client 配置。

## Overview

Bridge 连接 Slack app、MCP server 和 agent runtime。常见问题来自 token、scope、Socket Mode、slash command、channel bind 或 pending call 没有回复。

## Quick checks

- Socket Mode 是否开启。
- App token 和 bot token 是否正确。
- Bot scopes 是否包含需要的权限。
- Slash command 是否配置。
- Channel 是否已 bind。
- MCP client 是否连接 bridge server。

## Common causes

| Message or symptom | Likely cause | Recovery |
| --- | --- | --- |
| `Missing required env var: SLACK_BOT_TOKEN` | `.env` 没有 bot token | 添加 `SLACK_BOT_TOKEN=xoxb-...` 并重启 bridge。 |
| `Missing required env var: SLACK_APP_TOKEN` | `.env` 没有 Socket Mode app token | 添加 `SLACK_APP_TOKEN=xapp-...` 并重启 bridge。 |
| `Missing required env var: SLACK_SIGNING_SECRET` | `.env` 没有 signing secret | 从 Slack Basic Information 复制 `SLACK_SIGNING_SECRET`。 |
| `No channel bound. Use /zhi bind in a Slack channel first.` | 还没有绑定 channel | 在目标 channel 运行 `/zhi bind`。 |
| `/zhi` returns unknown command | Slash command text 不是 `bind`、`unbind` 或 `status` | 使用 `/zhi bind`、`/zhi status` 或 `/zhi unbind`。 |
| No Slack thread | Socket Mode 未开启、token 错误或 bot 未加入 channel | 检查 `connections:write`、`chat:write`，重新安装 app，并执行 `/invite`。 |
| Tool call hangs | Pending call 没有收到 thread reply | 在对应 Slack thread 回复，或取消 agent run；pending calls 默认不超时。 |
| Reply ignored | 缺少 `message.channels` / `message.groups`，或回复不是 thread reply | 添加 event subscription，并确保在 thread 内回复。 |
| Agent cannot call `zhi` | MCP config 未加载或 `ZHI_SOCKET_PATH` 不一致 | 检查 MCP client `command`、`args`、`env.ZHI_SOCKET_PATH` 和 bridge log。 |

## Verify commands

```text
/zhi bind
/zhi status
/zhi unbind
```

Bridge runtime logs should show:

```text
[slack-bot] Started in Socket Mode
[main] Zhi Slack Bridge running
[main] Socket: /tmp/zhi-bridge.sock
```

## Limits

Pending calls 默认不超时，除非你在 bridge 中配置或实现 timeout policy。
