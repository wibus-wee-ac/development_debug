Memories 是 Chronicle pipeline 对本地活动的摘要结果。它帮助 agent 或用户回顾上下文，但不替代原始项目文件。

## 先认识这个功能

Chronicle 可以暴露 resources、timeline、frames 和 memory search。Memory search 适合查找最近活动、上下文摘要或相关事件。

## 搜索 memory

1. 打开 Settings 的 Chronicle 区域。
2. 进入 memory search。
3. 输入与活动相关的关键词。
4. 查看返回摘要和时间线位置。

## 使用建议

- 用 memory 回忆上下文。
- 用 workspace 文件确认事实。
- 对敏感信息保持谨慎，不要假设过滤绝对可靠。

## 使用前先知道

Memory 是 pipeline 输出，可能受 capture 质量、OCR 质量、model 选择和 dedup 策略影响。
