Chronicle setup 用于确认本地 capture、资源、model 和 daemon 状态。它适合管理员或需要本地记忆能力的高级用户。

## 先认识这个功能

启用 Chronicle 前，先确认平台权限、资源安装和 model 可用。macOS screen capture 可能涉及系统权限，具体授权步骤以当前 app 和系统提示为准。

## 配置步骤

1. 打开 Settings。
2. 进入 Chronicle。
3. 选择用于 summarization 或 memory pipeline 的 model。
4. 打开 capture。
5. 查看 status 和 resources。
6. 在 timeline 中确认是否有新记录。

## 验证

检查：

- Capture 是否开启。
- Resource 是否可用。
- Timeline 是否更新。
- Memory search 是否能返回结果。

## 使用前先知道

- macOS Screen Recording permission、resource installation 和 daemon lifecycle 需要按当前平台验证。
- Model 选择影响 memory pipeline 质量和成本。
- Chronicle 不应被当成审计合规系统。
