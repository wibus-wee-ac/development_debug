当 Chronicle 没有产生 timeline 或 memory 时，先检查本地权限和资源状态，再检查 pipeline 输出。

## Overview

Chronicle 故障通常来自 capture 未启用、系统权限不足、resource 缺失、model 不可用或 daemon 未运行。

## Quick checks

- Settings 中 capture 是否开启。
- Status 是否显示运行中。
- Resources 是否安装或可访问。
- Timeline 是否有新 frame。
- Memory search 是否能返回近期结果。

## Common causes

| Symptom | Likely cause | Recovery |
| --- | --- | --- |
| No frames | Capture disabled or permission missing | 打开 capture 并检查系统权限 |
| No memories | Model unavailable or pipeline paused | 检查 model 和 resource |
| Empty search | No indexed memory | 等待 pipeline 或缩小搜索词 |
| High resource use | Capture or OCR workload | 调整 capture 设置 |

## Escalate

如果 status、resources 和 timeline 都异常，收集 Chronicle status、server logs 和 Devtools observability export。
