## 如何阅读这张地图

- 产品界面是日常使用路径：workspace、Chat、Kanban、automation。
- Agent 系统是执行路径：provider、model、runtime kind、skills。
- 本地记忆是 Chronicle 路径：capture、artifact、filtering、memory、recall。
- 开发者契约是贡献路径：server、OpenAPI、CLI、database。
- 扩展点是扩展路径：plugin SDK、web API、desktop API、first-party plugins。
- 恢复路径是排障路径：desktop server、provider、workspace Git、Devtools export。

## 第一选择

如果你正在学习 Cradle，先走产品界面。如果你在改代码，先走开发者契约。如果你遇到错误，先走恢复路径。

## 系统边界

<LocalFirstBoundaryMap />

Cradle 的核心边界是本地优先。外部 provider、Slack、browser automation 和 MCP 都通过显式 bridge 进入系统；它们仍然由各自的平台负责身份、权限和外部生命周期。
