Tabs 与 Sidebar 让你在同一个本地项目中同时处理 Chat、Kanban、文件、Git 和设置。

## Overview

Sidebar 提供主导航和 workspace drill-in。Tabs 保存当前打开的工作视图，并与 URL 同步。这样刷新页面或从桌面恢复窗口时，Cradle 可以回到可识别的状态。

## 常用动作

- 从 Home 打开 workspace。
- 从 `New Chat` 创建 session。
- 在 workspace group 中打开已有 session。
- 打开 Kanban board。
- 进入 Settings overlay。
- 使用 global search 找到 workspace 或 session。

## Session 管理

Session list 支持重命名、pin、导出和删除。删除会影响你之后查看该 session 历史的能力，操作前先确认导出需求。

## Limits

- 不同 tab 的状态由 Web app 管理，本地 server 只提供数据与运行时能力。
- 如果 URL 与 tab 状态不一致，优先从 sidebar 重新打开目标视图。
