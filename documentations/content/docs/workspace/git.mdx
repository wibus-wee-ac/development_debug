Git panel 帮助你在 Cradle 中查看当前 workspace 的源码状态。它适合确认分支、ahead/behind、fetch 状态和提交历史。

## 先认识这个功能

Git panel 主要用来查看当前 workspace 的 Git 状态：分支、ahead/behind、fetch 结果、提交图，以及非 Git 目录的提示。如果界面里没有 commit、push、pull 或 stash 入口，就继续在你熟悉的 Git 工具里完成这些操作。

## 查看状态

打开 workspace 的 Git panel，检查：

- 当前分支。
- ahead/behind。
- 远端 fetch 状态。
- commit graph。
- 是否是 Git repository。

## 非 Git 目录

如果 workspace 不是 Git 仓库，Git panel 会显示错误或空状态。你仍然可以使用 Chat 和文件能力，但 Git 相关视图不会提供分支信息。

## 遇到问题时

- 分支列表不更新：先使用 fetch，再检查网络和远端权限。
- commit graph 为空：确认目录包含 Git 历史。
- 权限错误：在终端中验证当前用户是否能读取 `.git` 目录。
