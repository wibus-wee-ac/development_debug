Workspace 是 Cradle 的日常工作界面。它把项目目录、session、Kanban、Git、文件、automation 和 plugin surfaces 放在同一个导航结构中。

## Overview

Web workspace 启动后会固定 Home tab，并通过 sidebar 进入 workspace group、New Chat、Kanban、plugins、global search 和 Settings。Tab 状态会与 URL 同步，方便恢复当前工作视图。

## 主要区域

- `Home`：workspace、session 和常用动作入口。
- `Sidebar`：workspace group、session list、Kanban、plugins 和 Settings。
- `Tabs`：打开 Chat、Kanban、Devtools 或其他视图。
- `Settings overlay`：配置外观、providers、agents、skills、Chronicle 和 desktop。

## 使用建议

把一个本地项目目录作为一个 workspace。围绕该 workspace 创建 Chat session、Issue、automation 和 Chronicle 记忆，避免跨项目混用上下文。

## 限制

- 文档不描述远程 workspace 或云端同步，因为当前证据集中在本地 app 与本地 server。
- Home 中的 mock pending run 和 mock artifact 不作为真实产品能力描述。
