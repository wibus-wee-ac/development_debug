Pack codebase 用于把项目结构和文件内容整理成一个上下文包。它适合在 Chat 中解释较大的改动范围，或把选中目录复制到外部工具。

## Overview

Pack codebase 读取当前 workspace 或选中路径，并生成可复制的文本输出。界面可能提供 ignore、remove comments、compress 等选项；具体输出格式以当前实现为准。

## 何时使用

- Agent 需要理解多个文件之间的关系。
- 单个 file mention 不足以表达上下文。
- 你要把 workspace 摘要复制到另一个 session。

## 操作路径

1. 在 workspace 中打开 pack codebase dialog。
2. 选择 workspace 或具体路径。
3. 调整可用选项。
4. 复制输出。
5. 粘贴到 Chat 或外部目标。

## Limits

- 大型仓库可能生成很长的上下文，发送前先确认目标 model 的上下文窗口。
- ignore 和 compress 的精确定义依赖当前 pack engine，不在文档中扩展为稳定协议。
