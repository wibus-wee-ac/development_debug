Search 用于在 Cradle 中快速跳转。它比逐层展开 sidebar 更适合切换到已有 session 或查找 workspace。

## 先认识这个功能

全局搜索从 Web workspace 入口打开，覆盖 workspace、session 和部分导航目标。它是 UI 跳转能力，不替代代码全文搜索或 provider model search。

## 使用方式

1. 打开 global search。
2. 输入 workspace、session 或目标名称。
3. 选择结果并进入对应 tab。

## 搜索边界

- Workspace search 和文档站搜索不是同一个索引。
- Provider model search 在 Settings 的 Providers 区域完成。
- 文件内容搜索能力以当前 workspace UI 为准，不在本页承诺。

## 遇到问题时

如果搜索不到 session，先确认 session 没有被删除，并从 workspace sidebar 手动查看列表。
