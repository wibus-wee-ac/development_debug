Automation 用于保存可重复执行的 agent 工作流。它可以包含 definition、trigger、enabled state、run history、links 和 artifacts。

## Overview

当前文档把 Automation 描述为 agent-authored automation registry and run viewer。UI 可从 Home 嵌入查看，dedicated tab 是否完整以当前实现为准。

## 主要对象

- Definition：自动化定义。
- Trigger：例如 RRULE。
- Run：一次执行记录。
- Artifact：执行产生的结果。
- Link：与外部或内部对象关联的引用。

## 使用方式

1. 查看 automation definitions。
2. 启用或禁用定义。
3. 手动 run now。
4. 查看 run history。
5. 检查 artifacts 和 links。

## Limits

创建和编辑 UI 的完整程度需要按当前 dashboard 实现验证。本文只承诺 server routes 和 UI 中可见的查看、启用、运行与历史能力。
