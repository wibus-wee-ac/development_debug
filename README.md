## Packages

| Package | Description | Status |
|---|---|---|
| [`@cradle/tabs`](./packages/tabs) | Activity-based tab management for React desktop apps. Uses React 19 `<Activity>` for tab lifecycle (frozen effects, preserved DOM), Zustand for state, and a registry pattern for tab types. | ![WIP](https://img.shields.io/badge/status-WIP-yellow) |
| [`@cradle/ipc`](./packages/ipc) | Type-safe IPC communication layer for Electron apps, built on top of `electron-ipc-decorator`. Provides a structured way to define IPC services with decorators, automatic type inference, and error handling. | ![Stable](https://img.shields.io/badge/status-Stable-green) |
