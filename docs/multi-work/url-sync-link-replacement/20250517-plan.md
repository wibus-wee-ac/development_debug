# URL Sync: Global `<Link>` Enhancement Plan

## Objective

Replace all direct `onClick → openTab()` navigation patterns with `<Link to="..." params={...}>` where the navigation target is known at render time. This gives users:
- Right-click → Copy Link
- Cmd/Ctrl+Click → Open in New Tab
- Middle-click → Open in New Tab
- Proper `<a>` semantics (accessibility, crawler-friendly)

### Out-of-Scope (Keep Programmatic)

- Post-creation redirects (after creating session → openTab)
- Keyboard shortcuts (Cmd+T)
- Command palette results
- Local UI tab switching (right-aside tabs, sub-tabs)

## Constraints

- Import `Link` from `@cradle/tabs-next`
- `<Link>` must preserve existing visual styling (use className pass-through)
- Where current element is a `<button>`, replace the outer element with `<Link>` styled as button
- Where the element has additional onClick logic (e.g. close dialog), keep the logic in Link's onClick prop (it runs before default prevention)

## Acceptance Criteria

- [ ] All 11 candidates above use `<Link>` component
- [ ] Cmd+Click opens in new tab from each navigation point
- [ ] Right-click shows browser "Copy Link" option
- [ ] No TypeScript errors
- [ ] No visual regressions (Link inherits styling from className)
