# Provider Model Cache + Lobe Icons Integration

## Objective

1. Add persistent DB-backed cache for provider model lists
2. Add "Fetch Models" button in Provider Settings that fetches + caches models
3. Integrate @lobehub/icons-static-svg for provider/model icons

## Architecture: Model Cache (Stale-While-Revalidate)

### DB Schema

Table: `provider_model_cache`
```sql
CREATE TABLE provider_model_cache (
  profile_id TEXT NOT NULL,
  models_json TEXT NOT NULL,  -- JSON array of ModelDescriptor[]
  fetched_at INTEGER NOT NULL, -- unix timestamp ms
  PRIMARY KEY (profile_id)
);
```

### Service Flow

```
Frontend: "Fetch Models" click
  → POST /providers/models (existing endpoint, enhanced)
  → Server fetches from provider API
  → Enriches with models.dev registry
  → Stores result in provider_model_cache table
  → Returns models to frontend

Frontend: Open settings / load models panel
  → GET /providers/:profileId/models-cache
  → Server reads provider_model_cache
  → If cache < 24h → return cached
  → If cache > 24h → return cached + trigger background refresh
  → If no cache → return empty (frontend shows "Click Fetch")

App startup:
  → warmupModelCache() — refresh all stale caches in background
```

### API Changes

1. **Existing** `POST /providers/models` — add DB write after successful fetch
2. **New** `GET /providers/:profileId/models-cache` — read from DB cache
3. **New** `POST /providers/:profileId/refresh-models` — explicit refresh (same as models but with profileId in path)

## Lobe Icons Integration

### Setup

- Package installed: `@lobehub/icons-static-svg` in apps/web
- Manifest: `src/assets/lobe-icons-toc.json` (301 entries with id, docsUrl, title, color, group)
- SVG files: `node_modules/@lobehub/icons-static-svg/icons/{docsUrl}.svg`

### Icon Utility Module

File: `apps/web/src/lib/lobe-icons.ts`

```ts
import tocData from '~/assets/lobe-icons-toc.json'

export interface LobeIconEntry {
  id: string
  docsUrl: string  // maps to SVG filename
  title: string
  fullTitle: string
  color: string
  group: 'model' | 'provider' | 'application'
}

export const lobeIconsToc: LobeIconEntry[] = tocData

// Vite glob import for SVG raw content
const svgModules = import.meta.glob(
  '/node_modules/@lobehub/icons-static-svg/icons/*.svg',
  { query: '?raw', import: 'default' }
)

export async function loadIconSvg(docsUrl: string): Promise<string | null> {
  const key = `/node_modules/@lobehub/icons-static-svg/icons/${docsUrl}.svg`
  const loader = svgModules[key]
  if (!loader) return null
  return (await loader()) as string
}

// Sync: build URL for <img> tag (uses Vite's static asset handling)
export function getIconUrl(docsUrl: string): string {
  return new URL(
    `../../../node_modules/@lobehub/icons-static-svg/icons/${docsUrl}.svg`,
    import.meta.url
  ).href
}
```
