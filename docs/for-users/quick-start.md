# Quick Start

This guide gets you from zero to a working Cradle session in minutes.

## 1. Install and Launch

1. Install dependencies in the project root:

```bash
pnpm install
```

2. Start Cradle in development mode:

```bash
pnpm dev
```

3. Wait until the Electron window opens.

For packaged builds, use the app bundle generated by your target build command (for example `pnpm build:mac`, `pnpm build:win`, or `pnpm build:linux`).

## 2. Add Your First Workspace

1. In the left sidebar, click the `+` action in the Projects section.
2. Select a local repository directory.
3. Confirm that the workspace appears in the sidebar.

Cradle treats each workspace as a local ownership boundary for sessions, rules, and context.

## 3. Configure Providers and Agents

Open `Settings` from the sidebar and configure:

1. `Providers`
   - Add or edit provider profiles (for example `openai-compatible`, `acp-chat`, or `cli-tui`).
   - Validate provider connectivity where applicable.
2. `Agents`
   - Create or edit agent identities.
   - Bind each agent to a provider profile and model.
   - Optionally set thinking effort and system behavior.
3. `Skills`
   - Add global reusable skills if needed.

## 4. Start Your First Session

1. Click `New Chat` in the sidebar.
2. Select workspace, provider profile, and model.
3. Enter a prompt and send.

Session behavior depends on provider kind:

- Chat providers render structured streamed messages.
- `cli-tui` providers render a native terminal view.

## 5. Optional: Open Your First Kanban Board

1. Click `Kanban` in the sidebar.
2. Create a board for the workspace if none exists.
3. Add issues and optionally delegate an issue to an agent profile.

## 6. Validate Core Features

After first setup, verify:

- You can reopen recent sessions from the sidebar.
- Search opens with `Cmd+K` or `Ctrl+K`.
- Usage dashboard shows token stats after at least one model response.
- Settings persist after relaunch.
