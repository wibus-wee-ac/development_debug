⏺ Cradle — Product Spec

一句话定位

给独立开发者用的 AI 工程团队指挥台。
你是 Tech Lead，Cradle 是你的作战室，里面跑着你的 AI 团队。

---

核心理念

传统开发工具让你操作「代码编辑器」。
Cradle 让你操作「一支 AI 工程小队」。

你的角色不是写每一行代码，而是：

- 决定做什么
- 把任务分派给合适的 agent
- 在关键节点审查和收口

---

人的工作模式

你 Agent
── ─────
选 Workspace →
开 Session →
描述任务 →
自主执行（读写代码、跑命令、处理错误）
← 到达关键节点（diff / test / PR）
审查 & 决策 →
继续或收口

不是全程盯，也不是完全 autopilot。
人在 orchestration 层，agent 在执行层。

---

功能模块

1. Workspace 管理

- 添加本地 repo 作为 Workspace
- 每个 Workspace 显示：repo 名、当前 branch、活跃 Session 数、最后活动时间
- 在 Finder/Explorer 或 IDE 中打开 Workspace（一键跳转）

2. Session（核心交互）

- 在 Workspace 内开一个 Session，选择使用哪个 Agent
- 主界面是 Chat UI：你输入任务，agent 回复执行过程和结果
- Agent 的 stdout 实时流式显示在对话里
- 支持同一 Workspace 开多个并行 Session（不同任务）

3. Agent 接入层

- Agent 以进程方式接入：Cradle spawn 一个 CLI 进程（如 claude、codex），读写 stdin/stdout
- Agent Registry：每种 agent 配置启动命令、参数、工作目录
- 插件式：新 agent 只需注册一条启动配置，不需要改 Cradle 核心代码
- 内建支持：Claude Code、Codex（后续扩展）

4. 作战盘视图

- 第一版：左侧 Workspace 列表 + 右侧 Session Chat，类似 IDE 侧边栏 + 主区
- 后续：多 Session 并排视图，一眼看到所有 agent 状态

5. 审查节点（后期）

- diff 审核面板
- 测试结果展示
- PR 提交流程

---

不做的事（明确排除）

- 不替代编辑器：Cradle 不是 IDE，没有代码编辑器，打开 IDE 是跳转行为
- 不做云同步：纯本地，数据不上云
- 不做团队协作：个人工具，不考虑多人共享
- 不自己实现 agent loop：直接复用成熟 CLI agent，不重复造轮子
