# Copy My Code

> Thanks to https://repomix.com/ for the inspiration.

将整个项目（Repository）压缩并格式化为单个 AI 友好型文件。它解决了手动复制粘贴代码时的“目录结构丢失”、“无用文件干扰”以及“Token 浪费”等痛点。

## A. 智能打包与格式化

* 多格式支持：支持导出为 XML（默认，AI 识别率最高）、Markdown、JSON 或 纯文本。
* 结构可视化：自动在输出文件开头生成整个项目的目录树结构，帮助 AI 快速建立全局视野。
* 文件元数据：每个代码块前都会标注完整的文件路径、行数及 Token 计数。

## B. 代码体积优化 (Token Saving)

* Tree-sitter 压缩 ：实验性核心功能。通过语法分析提取类名、函数名、接口定义等核心骨架，剔除具体实现逻辑，可在保留代码语义的同时显著减少 Token 消耗。
* 移除注释与空行：可选，进一步瘦身。
* Token 计数器（可选实现）：支持主流模型的 Token 预估，支持生成 Token 计数树以识别项目中的“大头”文件。

## C. 过滤机制 (Filter System)

* Git 感知：默认自动忽略 .gitignore 中的文件。
* 忽略策略：
1. 内置模式：自动排除 node_modules、.git、二进制文件等。
2. 用户选择

## D. 安全与合规

* 敏感信息扫描：内置 Secretlint，在打包时自动检测代码中是否包含 API Keys、密码或私钥，防止开发者意外将隐私发给 AI 服务商。

## 典型使用场景

1. 代码审计/重构：将整个项目打包发给 Claude/ChatGPT，让其分析架构并给出重构建议。
2. 生成文档：让 AI 根据完整的代码上下文生成 README 或 API 手册。
3. 单元测试补全：提供全局上下文，让 AI 为特定模块编写高覆盖率的测试用例。
