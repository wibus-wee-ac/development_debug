ELEVATION & DEPTH
Three tiers — no levitation

Depth is achieved through color separation, not shadows. Shadows exist only for genuinely floating layers.

Tier 1 — Spatial separation
Chrome bg-sidebar + content bg-background. The only permanent depth layer.
Tier 2 — Surface texture
inset-shadow 1px top highlight. Interactive tiles feel pressed-in, not floating.
Tier 3 — Floating layers
shadow-xl + backdrop-blur. Only for popovers, command palettes, modals.

DO'S & DON'TS
DO
✓ Use chrome/content color split as your entire depth model before reaching for shadows
✓ Use inset-shadow for surface texture on cards and interactive tiles
✓ Use tabular-nums on all numeric display content
✓ Use categorical color pairs: bg-[color]-500/10 text-[color]-500/60~70
✓ Use spring animations everywhere; match stiffness 500–600, damping 35–40
✓ Use text-pretty on wrapping prose titles and descriptions
✓ Use opacity-0 group-hover:opacity-100 to reveal secondary actions
DON'T
✕ Add shadow-xs/sm/md to list rows, sidebar items, or static UI
✕ Use uppercase tracking-wider font-semibold section labels
✕ Reduce primary content text opacity — hierarchy comes from size, not opacity washing
✕ Add hard borders between layout columns — use color separation instead
✕ Add per-item hover elevation (shadow on hover) — use background fill only
✕ Use standalone gradient backgrounds for UI surfaces
✕ Use cubic-bezier for elements that should feel physical — use spring
