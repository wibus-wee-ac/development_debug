# Features/Home

Dashboard hub feature for the root index route.
Replaces the chat-composer entry point with an activity-first hub view.
Place chat-related components in `features/chat/` or `features/new-chat/` instead.

## Files

- **home-dashboard.tsx**: Dashboard component — search bar, recent sessions across all workspaces, projects list, static activity card themes, and the Home projection/entry point for the automation registry.
